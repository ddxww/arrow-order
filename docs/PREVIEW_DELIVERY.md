# Windows 预览程序交付说明

本次程序是《一箭又一箭 · 箭序》的阶段 1 界面预览，用于查看奶油白、雾蓝紫配色以及布局。它与浏览器预览展示同一套界面，当前还不是完整可玩的游戏。

## 打开程序

1. 解压 `ArrowOrder-Preview-Windows.zip` 到任意普通文件夹。
2. 双击其中的 `ArrowOrder-Preview.exe`。无需安装 Python，也无需联网。
3. 程序为单文件封装，首次打开可能需要几秒。窗口可缩放，点击关闭按钮或按 `Esc` 退出。

交付 ZIP 包含 EXE、本说明和 `OFL.txt` 字体许可。单独领取或转发 EXE 时，也请保留同目录的 `OFL.txt`。

## 查看界面

| 按键 | 界面 |
|---|---|
| `1` | 首页 |
| `2` | 关卡选择 |
| `3` | 游戏 |
| `4` | 提示样例 |
| `5` | 碰撞样例 |
| `6` | 单关通关 |
| `7` | 失败 |
| `8` | 全部通关 |

可以从首页点击“开始游戏”查看游戏画面，也可以通过“选择关卡”等导航按钮切换样例。数字键可直接查看全部界面。

## 当前可用范围

已提供窗口缩放、中文文字、箭头和棋盘绘制、导航及 8 个静态状态样例。成绩、解锁状态、提示及碰撞均为演示数据。

点击棋盘暂不消除箭头或扣除机会；音效、真实提示、自动通关、关卡解锁和进度保存尚未实现。用户本人六关试玩尚未进行，本交付不代表完整游戏验收。
