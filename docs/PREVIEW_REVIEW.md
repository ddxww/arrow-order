## 真实发现与修改

1. 首轮渲染发现 Noto Sans SC 变量字体在当前字体引擎下默认字重过细。通过 fontTools 生成450和650静态字重，并保留GB2312和界面符号字形，改名为ArrowOrder Sans。最终图中文字粗细和辨识度已改善。
2. 游戏棋盘底部与反馈文本间距偏紧，缩小棋盘并增加留白。
3. 初始界面计数写成18，但展示布局实际为15，改为统计展示数组。
4. 最初所有结果页复用游戏初始背景；修改为各结果的静态状态，避免失败页仍显示3次机会、通关页仍显示完整布局。
5. 用户要求配色与参考项目不同。主色从青绿改为雾蓝紫，背景为奶油白，提示为暖杏，碰撞为莓红；同步修改所有Pygame画面和画廊。

## 检查边界

这些是**界面预览检查**，不是六关游戏的功能验收。尚未实施课程T01—T06、路径检测、动画状态、存档、音效、完整试玩或EXE检查。预览窗口的导航只切换样例，不能当作可玩版。

PNG已检查默认960×800画面。Pygame预览提供等比缩放与坐标映射，但完整游戏在多种窗口大小及高DPI设备下的可读性和点击命中仍需在阶段2验证。

## 审阅入口

打开 `previews/index.html`，左侧可切换8个画面。用户需确认配色、布局、箭头大小、文字清晰度；目前节点1尚未获用户确认。

## Windows 预览包验证（用户追加要求后）

使用 PyInstaller 6.22.3 构建 `dist/ArrowOrder-Preview.exe`。对该EXE执行 `--export --output build/exe-smoke`，在正常Windows环境无窗口导出8张图片并以0退出；8张图的SHA-256与源码生成结果全部相同。验证覆盖EXE启动、运行库、字体及所有预览画面，不代表真实消除玩法或本人试玩。
